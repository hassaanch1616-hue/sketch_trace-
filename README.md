# ✏️ SketchTrace

<div align="center">

### Draw Anything with Camera Tracing

A free, fast, and responsive web app that helps artists, students, and beginners trace images directly from their phone or computer.

🌐 **Live Demo:** https://sketchtrace.online/

⭐ **If you like this project, don't forget to Star the repository!**

</div>

---

## 🚀 Features

- 📷 Camera-based image tracing
- 🖼️ Upload custom images
- 🔍 Zoom In & Zoom Out
- 💡 Opacity & Brightness controls
- 🔒 Screen Lock while drawing
- 📱 Mobile-friendly
- 💻 Desktop & Laptop support
- ⚡ Fast and lightweight
- 🎨 Perfect for artists, students & beginners

```bash
cd sketch_trace-
```

Then open `index.html` in your browser.
